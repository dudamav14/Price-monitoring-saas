# 💻 Market Intelligence SaaS - Front-end Dashboard (React / Next.js)

Interface web analítica em **React** e **TypeScript** com **Tailwind CSS** e **Recharts** para monitoramento em tempo real de e-commerce e inteligência de sentimentos NLP.

---

## 🚀 Funcionalidades

- **Dashboard Executivo:** KPI cards com total de produtos, descontos médios e índice de aprovação NLP dos consumidores.
- **Tabela Interativa & Filtros:** Busca instantânea por palavra-chave, filtros dinâmicos de categoria (*Smartphones*, *Periféricos*, *Hardware*) e concorrente (*Amazon*, *Mercado Livre*, *Kabum*).
- **Gráficos Interativos (Recharts):** Séries temporais de variação de preço e gráfico de rosca de distribuição de sentimentos.
- **Modal de Raio-X com IA:** Detalhamento do produto com opiniões reais classificadas pelo modelo HuggingFace (BERT).
- **Acionamento em Tempo Real:** Botão para disparar o pipeline de scraping e IA direto pela interface.

---

## 🛠️ Execução Local

```bash
cd frontend
npm install
npm run dev
```

O dashboard estará disponível em: [http://localhost:5173](http://localhost:5173)
